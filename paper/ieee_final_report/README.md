# ContinualGuard IEEE course report

`main.tex` is the compilation entry point. This package includes the IEEE conference class and `IEEEtran.bst` supplied with the course template. Compile with **pdfLaTeX + BibTeX + pdfLaTeX twice**. In Overleaf, choose `main.tex` as the main document and pdfLaTeX as the compiler.

The report has 10 body pages plus one IEEE-format references page, 11 references, a 167-word abstract, results tables, vector figures, and a contribution statement using the authors' supplied division of work. The PDF is the course submission artifact; the ZIP is an editable Overleaf source project.

The revised source follows the supplied IEEE table example: table captions appear above the data, figure captions below the image. The capacity table spans the full text width to keep its numeric columns separate.

This source package contains no raw benchmark text, reviewer comments, or model checkpoints. Figures and numbers are inherited from the frozen ACL paper and validated project results. The earlier ACL paper and underlying experiment artifacts remain unchanged in their original project locations. The report does not claim independent malicious-stream confirmation or deployment readiness.

The public research-code repository is https://github.com/Ukino13t/ContinualGuard. The paper cites it in a Methodology footnote. Review the author affiliation and final wording before submission.
